# Module 1 - Power Generation

Generation and conversion for the Smart Grid Test Bench: the wall source and the emulated solar source, source selection, the 24 VAC supply to the transmission branches, and the 5 VDC control rail for the other modules.

**Status (November 24, 2026).** Design complete and recorded in the Design Report of November 3, 2026. Module files are added here as the module is built; proof-of-concept testing is scheduled for early December 2026.
