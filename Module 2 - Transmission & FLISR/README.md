# Module 2 - Transmission & FLISR

Transmission, fault protection, and restoration for the Smart Grid Test Bench: four transmission branches, each with a switchyard that detects a fault, isolates it, and restores service from a neighboring branch (FLISR).

**Status (November 24, 2026).** Design complete and recorded in the Design Report of November 3, 2026. Module files are added here as the module is built; proof-of-concept testing is scheduled for early December 2026.
