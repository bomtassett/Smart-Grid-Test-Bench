# Module 3 - Distribution & Load

Distribution and load for the Smart Grid Test Bench: four load modules representing six Charleston-area customers, the load control unit that sheds and restores them on command from Module 4, and the browser HMI, a client of the Module 4 supervisory API.

**Status (November 24, 2026).** Design complete and recorded in the Design Report of November 3, 2026. Module files are added here as the module is built; proof-of-concept testing is scheduled for early December 2026.
